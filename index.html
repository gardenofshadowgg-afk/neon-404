COMO JOGAR

Objetivo: desative todos os robôs de cada setor e depois encontre o portal luminoso. Colete cristais para aumentar sua pontuação.

Celular: use o círculo esquerdo para andar, deslize o dedo na metade direita para olhar, toque em DISPARAR para atirar e em ARMA para trocar.

Computador: W A S D para andar, ← → para girar, mouse para mirar, clique ou ESPAÇO para atirar, teclas 1/2/3 para armas, M para o radar, ESC para pausar.

Armas: blaster tem energia infinita, espalhador e plasma têm cargas limitadas. Colete caixas de energia para recarregar.

O progresso é salvo neste navegador ao concluir um setor. O jogo não utiliza contas, anúncios nem serviços externos.
